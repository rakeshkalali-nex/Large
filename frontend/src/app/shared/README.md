# Shared integration APIs

All controls are standalone; import from `shared/index.ts` or individual files.

- `ConfirmationService.confirm({title, recordName, message, confirmLabel?, requireReason?, destructive?})` opens a CDK alert dialog and returns `Observable<ConfirmationResult>`. Import `DialogModule` in the consumer/root providers. Only `{confirmed:true}` authorizes the caller to start its mutation. Required reasons are trimmed. Cancel, Escape and backdrop dismissal are safe cancellation. CDK manages focus trapping/restoration, with Cancel initially focused. The dialog never executes an HTTP mutation, so dismissal cannot interrupt one.
- `be-feedback`: required `title`; `kind` loading/empty/success/error/warning/info, `message`, optional `actionLabel`, and `action` output. Supply distinct empty explanations for no records/no assigned projects. Actions are explicit; nothing retries automatically. Pass safe messages only, never raw HTTP bodies.
- `be-form-field`: required `controlId` and visible `label`, optional `hint`, `error`, `required`. Project one native input/select/textarea carrying `beFieldControl`; import `FieldControlDirective`. The field wires the ID, required state, invalid state and descriptions, preserving other described-by IDs and native values. Keep controlId stable and unique.
- `validationMessage(control, submitted)` maps Angular validation states to safe text, without modifying values. `be-validation-summary` accepts `errors: {controlId,message}[]`; call its `focus()` after submit rejection and rendering, not during typing. Links focus corresponding fields.
- `be-pending-button`: required `label`, optional `pending`, `pendingLabel`, `disabled`, `variant` primary/secondary/destructive; `activated` output. Native button is deliberately type=button. For both clicks and form submits, route work through one `PendingAction.run(() => promise)` and bind its `pending`. The synchronous guard prevents concurrent calls even before rendering; failures propagate and unlock without retry. Keep idempotency keys and authoritative mutation policy in the HTTP/state layer.
- `formatCurrencyMinor(integerDecimalString, {timezone,currencyCode,currencyMinorDigits,locale?})` formats exact minor units, including values beyond Number's safe integer limit, without rounding or deriving business totals. Currency and precision must come from confirmed company settings, never defaults. `formatDateOnly(YYYY-MM-DD, locale?)` validates calendar dates and never shifts them by timezone. `formatCompanyTimestamp(timestamp, {timezone,locale?})` requires explicit timestamp offsets and uses the company's IANA timezone. Invalid input/configuration throws; callers should render a safe unavailable state rather than invent a value.

Global theme ownership includes CDK overlay structural CSS and inherited typography. Components include local layout, focus and status treatments; the spinner respects reduced motion. Browser keyboard containment, responsive widths, zoom and assistive-technology announcement checks remain task 30 acceptance work; TestBed DOM checks are not real-browser evidence.
