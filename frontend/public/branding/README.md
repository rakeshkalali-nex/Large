# Original BuildEstate artwork

`buildestate-mark.svg` and `architectural-lines.svg` were drawn for this project as original geometric building-line artwork. No stock assets, external images, scripts or third-party logos are embedded. These project assets follow the application's licensing; no separate third-party artwork license is required or granted here.

Pair the mark with live `BuildEstate` text in IBM Plex Sans 600/700 for the wordmark. Give a standalone mark image `alt="BuildEstate"`; use empty alt when adjacent text already names it. The line illustration is decorative: use it as a CSS background on navy, or an image with empty alt. Do not expose its title as redundant screen-reader content. No font is embedded in either SVG.
